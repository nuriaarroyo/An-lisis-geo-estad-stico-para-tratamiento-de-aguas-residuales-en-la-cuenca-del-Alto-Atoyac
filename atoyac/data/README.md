# Datos del proyecto

`raw/` conserva entregas originales y `processed/` catálogos o compilaciones de trabajo. No son la carpeta de lectura pública del proyecto.

- [Manifiesto local](MANIFIESTO_FUENTES.csv): rutas, tamaños y hashes.
- [Fuentes e interpretación](../../docs/FUENTES.md).
- [Reconstrucción](../../docs/REPRODUCIR.md).

Los archivos nuevos de estas carpetas se ignoran en Git. El manifiesto identifica lo que se utilizó, pero no descarga las fuentes ni implica que un clon las contenga. Las tablas y capas seleccionadas para lectores están en `entrega/datos` desde la raíz del repositorio.
